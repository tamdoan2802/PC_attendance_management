# Employee Attendance Management Skill

This skill automates and standardizes the entire end-to-end workforce attendance evaluation lifecycle for **MyTeam Vietnam Company Limited**. It serves as an automated **Senior Workforce & People & Culture Analyst**, synthesizing raw MISA biometric timesheet punch clocks with 6 MISA application modules, reconciling against Master Data Entities, screening for **Burnout Risks**, evaluating the 5 core operational pillars, and drafting executive review reports.

## 🛑 MANDATORY POLICY: 100% DRAFT-ONLY & HUMAN-IN-THE-LOOP

> [!CAUTION]
> ### ABSOLUTE SAFETY POLICY:
> 1. **100% DRAFT ONLY:** All People & Culture review emails generated by this skill (`draft`) MUST ALWAYS BE SAVED AS DRAFTS (saved to Outlook Drafts via `.Save()` and displayed via `.Display()`).

## 1. The 5 Core Operational Attendance Pillars

The skill evaluates employee attendance across 5 operational pillars established in the **Attendance Semantic Reference Framework**:

```
                       ATTENDANCE OPERATIONAL FRAMEWORK (5 PILLARS)
                                           │
      ┌───────────────────┬────────────────┴───────────────────┬───────────────────┐
      ▼                   ▼                                    ▼                   ▼
   PILLAR 1            PILLAR 2                             PILLAR 3            PILLAR 4 / 5
  Punctuality     Departure Regularity                      Adherence       Stability & Intensity
  • Grace <=5m    • Approved OT (Paid / Banked)            • Actual vs      • Manual Overrides <= 1/mo
  • Excused vs    • Make-up Time (làm bù)                    Standard       • Leave Notice Classification:
    Unexcused     • BURNOUT RISK (>=3 consecutive days)    • Under/Over       - Sudden: <= 1 day
  • Chronic >30m  • Overwork Index                           Capacity         - Short: 2 - 7 days
    (unexcused)                                                             • Overtime Tiers (1 / 2 / 3)
                                                                            • Client Capacity Loss
```

### Pillar 1: Punctuality (Start-of-Shift Discipline)
- **5-Minute Grace Period:** Check-in up to 5 minutes after shift start is compliant and not penalized.
- **Excused vs. Unexcused:** Reconciled directly with `Đăng ký đi muộn, về sớm_Tất cả đơn vị.xlsx`.
- **Chronic / Severe Lateness:** Check-in $> 30$ minutes late **WITHOUT valid reason or approved request (strictly unexcused)** $\ge 2$ times within an evaluation cycle triggers a formal review flag. If supported by an approved request, it is an excused variance, NOT a disciplinary violation.

### Pillar 2: Check-out Regularity & Burnout Risk Screening
- **Make-up Time (Làm bù):** Automatically identifies when an employee stays late to offset earlier morning lateness.
- **Overtime vs Unapproved Late Stay:** Differentiates between formally authorized OT (`Đơn_đăng_ký_làm_thêm`) and unapproved late staying.
- **Burnout Risk Trigger:**
  $$\text{Late Check-out } > 30\text{m without approved OT for } \ge 3\text{ consecutive working days} \implies \mathbf{FLAG:\text{ }BURNOUT\text{ }RISK}$$

### Pillar 3: Capacity Adherence & Working Time
- **Actual Days vs. Working Days:**
  - `Working_Days` includes actual attendance, approved annual leave, and statutory public holidays.
  - `Actual_Days` reflects physical presence or approved WFH sessions.
- **Adherence Rate:** Ratio between actual hours worked and standard contractual hours (target: 98% – 102%).

### Pillar 4: Operational Stability & Leave Taxonomy
- **Macro Leave Categories:** Annual & Personal, Health & Family Care, Statutory & Welfare, Compensatory.
- **Notice Lead Time Taxonomy (Updated):**
  - **Sudden Notice:** Báo trước $\le 1$ ngày (Trước 01 ngày).
  - **Short Notice:** Báo trước 2 &ndash; 7 ngày (Từ 2 đến 7 ngày).
  - **Prompt Notice:** Báo trước 8 &ndash; 29 ngày.
  - **Planned / Normal:** Báo trước $\ge 30$ ngày.
- **Manual Override Policy:** $\ge 2$ manual adjustments ("Cập nhật công") within 1 month $\implies$ **Procedural Violation Flag**.

### Pillar 5: Workload Intensity & OT Tiers
- **Tier 1 (Light):** $\le 60$ minutes.
- **Tier 2 (Moderate):** 61 – 120 minutes.
- **Tier 3 (Heavy/Red):** $> 120$ minutes.
- **Overwork Index:** Measures aggregate pressure from approved OT and unapproved late departures.

## 3. 5-Step Standard Operating Procedure (SOP)

### Step 1: Run Attendance Quality Audit (`report`)
Generates the comprehensive 5-pillar report in markdown and HTML:
```bash
# Analyze previous completed calendar week (Mon-Sun):
python scripts/process_attendance.py report last_week

# Analyze custom date range:
python scripts/process_attendance.py report 2026-08-24:2026-08-30
```

### Step 2: Screen Priority Governance Alerts (`anomalies`)
Inspects only prioritized action triggers (Burnout Risks, Chronic Lateness without excuse, Manual Override abuse, Bottlenecks):
```bash
python scripts/process_attendance.py anomalies 2026-08-24:2026-08-30
```

### Step 3: Individual Employee Drill-Down (`employee`)
Inspects individual daily punch timestamps, shifts, and exception notes:
```bash
python scripts/process_attendance.py employee "Linh Ho" 2026-08-24:2026-08-30
python scripts/process_attendance.py employee MTVN0008 2026-08-24:2026-08-30
```

### Step 4: Create Outlook Email Draft (`draft`)
Creates an executive HTML email draft in Microsoft Outlook for P&C Management:
```bash
python scripts/process_attendance.py draft 2026-08-24:2026-08-30
```
- **To:** `ChauH@myteamsolution.com.au`
- **Subject:** `MyTeam _ Weekly Workforce Attendance Quality Report _ {Period}`
- **Action:** Saved to Drafts and displayed on screen for human review.

### Step 5: Launch Workforce Attendance Dashboard (`dashboard`)
Regenerates the complete attendance analytics dataset directly from raw timesheet files in `data/Attendance/Timesheet/`, raw request modules in `data/Attendance/`, and Master Data `entities/` (saved to `references/data.js` and `references/data.json`) and opens the interactive **Workforce Attendance Dashboard** in the default web browser:
```bash
# Refresh data and open dashboard:
python scripts/process_attendance.py dashboard

# Open dashboard directly without regenerating data:
python scripts/process_attendance.py dashboard --no-refresh
```
- **Dashboard UI:** 100% identical to the corporate template at `https://tamdoan2802.github.io/PC_attendance_management/reports/index.html`.
- **Tabs included:** Overview, Attendance Quality, Leave, OT & WFH, Requests Operations, Attendance Dashboard.
